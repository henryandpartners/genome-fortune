# Genome Fortune

Decode Your Destiny — merging ancient cosmology with epigenetic algorithms.

## Engines

| Engine | System |
|--------|--------|
| Bazi | Chinese Four Pillars of Destiny |
| I Ching | Oracle Hexagrams (64) |
| Thai Horasat | Thai day-based astrology |
| Vedic | Jyotish Moon sign + Nakshatra |
| Aztec | Tonalpohualli (260-day sacred calendar) |
| Western | Sun sign + Moon phase |
| Chinese Zodiac | Animal + Element + Yin/Yang |
| Numerology | Pythagorean + Chaldean + Soul Urge |
| Palm Analysis | Canvas-based palm line detection |

## Quick Start

Open `index.html` in a browser. No build step needed.

## Mobile App

```bash
npm install
npx cap add ios    # or android
npx cap sync
npx cap open ios   # opens Xcode
npx cap open android  # opens Android Studio
```

## Share

Results can be shared as image, text, or tweet from the result screen.

## Tech

Vanilla JS + HTML + CSS. Zero dependencies for core engine. Capacitor for mobile.
